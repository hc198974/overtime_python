# Overtime Money 计算工具

这是一个基于 Python 的加班与串休管理工具，主要结合 Excel 数据和日历信息，帮助生成 `计算结果.xlsx` 并按规则扣减串休。

## 当前功能

- 从 `原始数据.xlsm` 生成 `计算结果.xlsx`
- 自动识别 `计算结果.xlsx` 中 `记录表` 和 `统计表` 的职号/姓名信息
- 通过 `Crili` 从万年日历网站获取指定年月的工作日、公休日、节假日信息
- 计算 `统计表` 中符合条件的加班时长，并按“工作日 → 公休日 → 节假日”顺序扣减串休
- 在 `统计表` 的 K 列写入扣减结果，扣减值保存为负数
- 提供“清空 K 列”功能，可清除特定职号和年月对应的 K 列扣减记录

## 目录结构

- `overtime.py`
  - 主入口脚本
  - 加载 `计算结果.xlsx` 并对 `统计表`、`记录表`、`明细表` 进行加班统计
- `demos.py`
  - `Crili`：获取节假日/工作日数据
  - `Cwindow`：旧版月份输入窗口与计算入口
  - `Cmacro`：调用 Excel 宏处理 `原始数据.xlsm` 并生成 `计算结果.xlsx`
- `huanxiu.py`
  - 串休扣减工具 GUI
  - 支持职号自动填姓名、年月默认上个月、输入串休时长后扣减 K 列
  - 支持清空指定职号+年月的 K 列记录
- `requirements.txt`
  - 项目依赖清单
- `原始数据.xlsm`
  - 源数据文件（需手动提供）
- `计算结果.xlsx`
  - 计算结果文件，`huanxiu.py` 和 `overtime.py` 均读取/写入该文件

## 依赖

推荐使用 Python 3.8+。当前依赖如下：

- lxml~=4.6.1
- openpyxl~=3.0.5
- requests~=2.24.0
- future~=0.18.2
- pandas~=1.1.3

## 使用说明

### 1. 生成计算结果文件

1. 将 `原始数据.xlsm` 放在项目根目录。
2. 在 Windows 环境中运行：

```bash
python overtime.py
```

3. `overtime.py` 会读取 `计算结果.xlsx` 中的 `记录表`、`统计表` 和 `明细表`，并完成加班统计写回。

### 2. 串休扣减操作

1. 运行串休扣减工具：

```bash
python huanxiu.py
```

2. 在窗口中：
   - 输入“职号”
   - 程序会自动从 `计算结果.xlsx` 的 `记录表` 中填入“姓名”
   - “年月”默认填为上个月，格式为 `YYYY-MM`
   - 输入“串休时长”
   - 点击“抵扣串休”进行扣减

3. 扣减规则：
   - 读取 `计算结果.xlsx` 的 `统计表`
   - 仅对当前职号与当前年月的数据生效
   - 根据 `Crili.parseHTML` 获取每天的倍率
   - 先使用工作日（倍率 1.5）加班时长抵扣
   - 再使用公休日（倍率 2）
   - 最后使用节假日（倍率 3）
   - 扣减结果写入 `统计表` 的 K 列，并且写入值为负数
   - 每次输入同一个人同月的串休不会删除K列，会从头进行不完全覆盖计算

4. 如果加班时长不足，会弹出错误提示并停止保存。

### 3. 清空 K 列

- 点击窗口中的“清空 K 列”按钮，
- 会清除与当前职号和年月对应的所有 `统计表` K 列值。

## 注意事项

- `huanxiu.py` 会直接读取并修改 `计算结果.xlsx`，请使用前备份数据。
- `huanxiu.py` 的 `年月` 输入格式为 `YYYY-MM`，例如 `2026-05`。
- 连续多次点击“抵扣串休”时，程序会重新计算并不全面覆盖 `K` 列值，不会自动累加以前的扣减结果。
- 如果需要重新生成 `计算结果.xlsx`，请先运行 `overtime.py` 或使用 `demos.py` 的数据处理功能。
- 由于 Excel COM 自动化依赖 Windows 平台，涉及 `原始数据.xlsm` 的处理仅适用于 Windows。

## 代码说明

- `Crili`：抓取并解析万年日历数据，按日期输出倍率。
- `Cmacro`：调用 Excel 宏处理原始数据并生成 `计算结果.xlsx`。
- `App`（`huanxiu.py`）：串休扣减 GUI，支持自动填姓名、扣减 K 列、清空 K 列。
- `overtime.py`：现有主入口，用于执行整体加班统计与结果写回。
