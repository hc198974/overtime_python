# Overtime Money 计算工具

这是一个基于 Python 的加班统计与加班费计算工具，主要用于从 Excel 工作簿中读取考勤记录、识别节假日/工作日，并将计算结果写回工作簿。

## 主要功能

- 通过 GUI 窗口选择月份并启动计算
- 从万年日历网站获取指定月份的工作日、公休日和节假日信息
- 处理 `原始数据.xlsm` 并生成 `计算结果.xlsx`
- 计算统计表中的加班小时数，并填写“统计表”“记录表”“明细表”
- 自动区分普通班和夜班人员，并按照不同类型计算加班费/串休

## 目录结构

- `overtime.py`：主入口脚本，用于加载 Excel、收集职号并触发计算流程
- `demos.py`：包含日历抓取、GUI 窗口、Excel 宏执行和辅助类
- `requirements.txt`：项目依赖列表
- `原始数据.xlsm`：源数据文件（需存在于项目目录）
- `计算结果.xlsx`：计算结果文件，运行时会读取/写入该文件

## 依赖

推荐使用 Python 3.8+。项目依赖如下：

- lxml
- openpyxl
- requests
- future
- pandas
- numpy
- pywin32（通过 `win32com.client` 调用 Excel 宏）

可通过下面命令安装依赖：

```bash
pip install -r requirements.txt
```

> 注意：`win32com` 依赖通常随 `pywin32` 安装。如果没有，请额外安装：
> `pip install pywin32`

## 运行说明

1. 确保 Windows 系统上已安装 Microsoft Excel。
2. 将 `原始数据.xlsm` 放在项目根目录，同时确保Excel能运行原始数据.xlsm中的宏。
3. 运行主脚本：

```bash
python overtime.py
```

4. 弹出 GUI 窗口后：
   - 点击“获取月份”可输入要计算的月份
   - 点击“处理数据”会调用 Excel 宏处理源数据
   - 点击“开始计算”关闭窗口并继续执行加班计算

5. 程序会读取 `计算结果.xlsx` 中的 `记录表`、`统计表`、`明细表`，并将结果写回同一个文件。

## 注意事项

- 当前节假日逻辑以内置的 `2026` 年节假日列表为准，如需计算其他年份，需在 `demos.py` 中更新 `holiday_3x` 列表。
- 该工具依赖 Excel COM 自动化，因此只能在 Windows 平台上使用。
- 如果直接关闭 GUI 窗口，程序会退出，不会继续执行计算。

## 代码概览

- `Crili`：抓取并解析节假日日历数据
- `Cwindow`：控制 GUI 窗口交互与按钮事件
- `Cmacro`：调用 Excel 宏处理原始数据并生成计算文件
- `Count`：核心加班统计逻辑，负责填写 `统计表`、`记录表` 和 `明细表`
