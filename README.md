## 运算逻辑说明（overtime.py）

本程序对「船台二部」每人、每月的加班进行计算：先按日历类型算出每条打卡记录的**加班时长**，再把每人当月总时长按 **36 小时封顶** 拆成「转加班费」和「转串休」两部分。

### 1. 数据来源与列结构

- 输入文件：`计算结果.xlsx`
  - **汇总表**：每行一条打卡记录，列为（从 0 计数）
    | 索引 | 列名 | 含义 |
    |---|---|---|
    | 0 | 姓名 | 员工姓名 |
    | 1 | 日报日期 | 打卡日期 |
    | 2 | 签到 | 上班时间 (`time1`) |
    | 3 | 签出 | 下班时间 (`time2`) |
    | 4 | 月份 | 所属月份（程序只处理 GUI 选定的那个月） |
    | 5 | 节假日 | 日类型标签（工作日 / 节假日），计算时回填 |
    | 6 | 加班或串休 | 标记「转加班费」/「转串休」，计算时回填 |
    | 7 | 时长 | 当条加班小时数，计算时回填 |
  - **中干**：第 2 行为日期表头，第 3 行起每人一行，用于写汇总结果。
- 日历来源：`Crili(年份, 月份).parseHTML()` 抓取万年历网站，返回字典
  `result[日期(%Y%m%d)] = 日类型`，取值：
  - `1.5` = 工作日
  - `2` = 周末
  - `3` = 法定节假日

### 2. 单条记录的加班时长计算（changeHour）

逐人遍历「汇总表」中**当月**的行，仅对 `签到 < 签出` 的记录计算，按日类型分两套规则。

#### 2.1 工作日（result == 1.5）
- **只有下班 > 18:00 才计加班**。
- 时长 = 签出 − 17:30（精确到秒，最后 `/3600` 并保留两位小数）。
- 若 签出 ≤ 18:00，时长记为 0。
- 回填标签：列 5 = `"工作日"`。

#### 2.2 周末 / 节假日（result == 2 或 == 3）
先对上下班时间做**边界归一化**，再按时段扣午餐：

**签到归一化**
- 若 签到 > 8:00 且落在 12:00–13:00 → 按 12:00 算；
- 若 签到 ≤ 8:00 → 按 8:00 算；
- 其余（8:00–12:00、≥13:00）保持原值。

**签出归一化**
- 若落在 12:00–13:00 → 按 13:00 算；
- 其余保持原值。

**时长公式**（归一化后计算，扣减午餐）
- 签出 ≤ 12:00：时长 = 签出 − 签到 − 0.5h；
- 签出 ≥ 13:00 且 签到 ≤ 12:00：时长 = 签出 − 签到 − 1.5h；
- 签出 ≥ 13:00 且 签到 > 12:00：时长 = 签出 − 签到 − 0.5h；
- 时长 < 0（跨午夜等异常）记为 0，否则取两位小数。

> 注：周末与节假日在此分支一并处理，标签统一回填为 `"节假日"`。

### 3. 36 小时封顶转加班费（count2name，按人独立计算）

每人当月所有加班时长汇总后，按「36 小时内转加班费、超出部分转串休」的政策拆分：

1. 取出该人当月 `{日期: 时长}` 字典，按日类型拆成三组，优先级：**dict_3(节假日, 权 3) > dict_2(周末, 权 2) > dict_1(工作日, 权 1.5)**。
2. 若合计 ≤ 36h：全部计入「转加班费」(cash)。
3. 若合计 > 36h：`remainder` 初始为 36，按 dict_3 → dict_2 → dict_1 优先级依次填充：
   - 每组内用 `itertools.combinations` 枚举多个组合规模（`get_dict_start` / `get_dict_end` 给出起止规模），在所有「总和 ≤ remainder」的组合里挑**总和最大**的子集加入 cash（转加班费）；
   - 每填完一组，`remainder -= 已选总和`，继续下一组。
   - 因为日类型权重 3 > 2 > 1.5 严格有序，算法会优先把高价值（节假日/周末）日纳入加班费，使「转串休」尽量落在低价值的工作日。
4. 写回标记：某日时长若属于 cash → 列 6 标记「转加班费」，否则「转串休」。

> 该组合枚举法在数据量小时很快；当某人加班天数较多（约 ≥20 天）时组合数指数膨胀、会变慢。`overtime_fast.py` 用 0-1 背包动态规划（DP）解决了这一点（详见该文件）。

### 4. 中干汇总（setContents）

「中干」sheet 第 2 行为日期表头，第 3 行起每人一行：
- 各日期列：写入该人当天时长；
- 第 34 列「合计」= 当月时长之和；
- 第 35 列「可串休时间」= 合计 − 转加班费部分（cash）之和。

### 5. 主流程

```
Cwindow 选月份 → Crili 抓日历 → 读「中干」拿到姓名列表
  → changeHour 算每条时长
  → 逐人 count2name 做 36h 分配并写「中干」
  → 保存 计算结果.xlsx
```

> 年份在 `overtime.py` 内硬编码（`Crili(2026, …)`），换年需手动改；`overtime_fast.py` 已改为跟随 GUI 月份 + 当前年份自动推断。
